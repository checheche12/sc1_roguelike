# 스타크래프트 캠페인 로그라이크

스타크래프트 리마스터의 본편·브루드워 캠페인에 누적 재능, 저주, 추가 공세를 적용하는 Windows용 모드입니다. 기본 캠페인 순서와 원래 임무 목표를 유지합니다. 배포본에는 전용 실행기와 Python 실행 환경이 포함되어 있습니다.

## 다운로드·설치

1. **[최신 배포본](https://github.com/checheche12/sc1_roguelike/releases/latest)**에서 `SC1_Roguelike_*.zip`을 받습니다. GitHub의 `Source code (zip)`은 개발 소스입니다.
2. ZIP **전체를 쓰기 가능한 폴더에 압축 해제**합니다. 압축 파일 안에서 바로 실행하지 마세요. `Start_Campaign.exe`, `runtime`, `sc1` 폴더를 함께 보관합니다.
3. 실행 중인 스타크래프트를 종료하고 **`Start_Campaign.exe`**를 실행합니다. `Campaign_Patcher.exe`도 같은 관리자를 엽니다. 별도 Python 설치나 바로가기 파일은 필요 없습니다.
4. 관리자에서 새 캠페인 기록을 만들거나 기존 기록을 선택하고, 스타크래프트 설치 경로를 지정합니다. **캠페인 패치를 설치한 뒤 `스타크래프트 시작`**을 누릅니다.
5. 게임의 싱글 플레이 캠페인 메뉴에서 임무를 **새로 시작**합니다. 모드는 전용 실행기를 통해 켠 게임에 적용됩니다.

지원 기준은 **Windows 64비트 / StarCraft Remastered 1.23.10.13515**입니다. 스타크래프트 게임 설치가 별도로 필요합니다. 패치는 게임 설치 폴더의 `SC1CampaignGrowth`에 배치됩니다.

## 업데이트와 기록

새 ZIP은 새 폴더에 압축 해제하고 같은 절차로 패치를 설치합니다. 기존 성장 기록은 이전 배포 폴더의 `sc1/data`에 있습니다. 관리자에서 **기존 기록 파일을 선택**할 수 있으므로, 기록을 확인하기 전에는 이전 폴더를 지우지 마세요. 재능·저주 선택과 임무 완료 기록은 자동 저장됩니다. 임무 도중의 게임 저장·불러오기는 지원하지 않습니다.

## 이번 수정

- 일반 추가 공세는 기본 4분부터, 이후 90초 간격입니다. 기지 확보가 필요한 임무는 확보 후 준비 시간을 적용하며, 생산이 없는 임무에는 추가 공세를 보내지 않습니다.
- 공세가 알림 뒤 생성되지 않던 공중 전용 지점과 중립 자원 판정을 수정하고 물량을 늘렸습니다. 모습이 드러난 뒤 4초 후 출발합니다.
- 일꾼 지역 뮤탈리스크는 중첩에 따라 2·6·12·20기씩 직접 등장합니다. 후속 예비대는 혼합 병종으로 강화했습니다.
- 일반 방어력 재능은 +0.5, 보병 공격력은 +10%, 정밀 핵 유도 경고는 5초입니다. 영웅 표적 지시탄은 5초 동안 방어력을 제거합니다.
- 고급 기동대를 강화하고 희귀 레이너의 특공대 수량을 2배로 늘렸습니다. 일반 무작위 재능의 전설 확률은 1%, 영웅은 5%이며, 보장 전설 선택은 후보 4개를 제공합니다.
- 저주는 임무마다 `일반 → 진행도에 따른 상위 등급 → 일반` 순서로 제공합니다.
- 기존 가스 수량을 유지하면서 광물을 완만한 곡선으로, 가스를 곡선 옆에 함께 배치합니다. 가스가 하나면 한쪽, 둘이면 양쪽입니다. 지형·기존 건물·채취 동선 때문에 안전하게 배치할 수 없는 곳은 기존 기능 배치를 유지합니다.
- 버티기 임무에는 적 기지 전멸로도 승리할 수 있다는 안내를 표시합니다. 각 캠페인 최종 임무의 마지막 재능·저주 선택은 생략하고 완료 저장 후 축하 문구를 표시합니다. 시작·중간 선택은 유지합니다.

전체 63개 지도에 구조·자원 배치 검사를 적용합니다. 공세 생성은 실제 배치 유닛을 불러온 모의 검사로 확인했습니다. 모든 임무의 실전 완주·전투 밸런스·화면 외관 검증은 진행 중입니다.
