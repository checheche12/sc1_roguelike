# QA29 공중 병력·야마토·성능 보완

마린 삼점사는 기본탄 100%와 추가탄 두 발 각각 35%로, 모두 명중하면 170%입니다. 추가탄은 다른 삼점사를 재발동하지 않습니다.

테란 유도탄 재탐색은 고급으로 내려 레이스·발키리·배틀크루저에 사거리 1타일과 이동 속도 20%를 제공합니다. 레이스·배틀크루저는 이동 명령과 목적지를 보존하며 사격합니다. 발키리는 원래 미사일 발사 동작을 유지합니다. 저그 비행체 장갑의 가디언·디바우러와 프로토스 비행체 장갑의 스카웃·캐리어·아비터에도 사거리 1타일과 이동 속도 20%를 추가합니다. 이 기동 보너스는 첫 선택에만 적용합니다. 세 종족 공중 조달의 비용 20% 감소에 생산 시간 20% 감소를 추가하고, 프로토스 함대 교본에는 공격 주기 4.5% 감소를 제공합니다.

전방위 전함은 일반 공격 네 번마다 에너지 없이 기본 피해의 야마토 한 발을 발사합니다. 지상·공중 추가 포대의 피해는 100%로 조정합니다. 추가 포대와 자동 야마토는 충전을 쌓지 않으며, 자동 야마토는 삼중 야마토의 추가탄을 만들지 않습니다.

삼중 야마토 또는 전방위 전함을 보유하면 수동 야마토의 준비 동작도 빨라집니다. 전함의 CastSpell이 생성하는 충전 이미지 543, 스크립트 314의 발사 전 대기 22개를 2에서 0으로 줄입니다. 원래 대기 해석은 값에 한 프레임을 더하므로 해당 구간은 66에서 22프레임이 됩니다. 실제 프레임·소리·발사 명령과 발사 후 동작은 유지하며 에너지·대상 검사를 우회하지 않습니다. 적, 무력화된 전함, 다른 이미지·명령에는 적용하지 않습니다. 두 전설을 함께 선택해도 가속은 중복되지 않습니다.

오리지널 캠페인에서는 네이티브 방어력 보너스 함수가 브루드워 모드 조건 때문에 울트라의 키틴질 장갑을 제외했습니다. 실행 파일과 분기 증거를 확인한 뒤 이 함수가 기존 울트라 분기를 사용하도록 연결했습니다. 일반 방업과 키틴질 +2, 연구 여부, 소유자 구분을 유지하며 게임 모드 자체는 변경하지 않습니다. 이는 피해 계산과 방어력 표시가 함께 사용하는 함수입니다.

성능 보완은 단계별 불변 스탯 편집 목록의 반복 선형 탐색을 인덱스로 바꾸고, 소유자 스코프의 불필요한 배열 초기화를 제거합니다. 240 활성 프레임마다 콜백 구간별 평균·최대 시간과 외부 엔진 작업을 포함하는 프레임 간격을 `PERF runtime` 로그에 기록합니다. 사용자 세션에서 렉의 원인은 확정되지 않았습니다. 오프라인 측정 개선을 실제 게임 프레임 개선으로 간주하지 않습니다.

검증은 네이티브 프로덕션 호스트, 선택 UI, Python 성장·재접속·후보 보존 검사와 변경하지 않은 63지도 체크포인트 검사입니다. 울트라 회귀는 읽기 전용으로 관측한 명령을 재구성한 동등 실행 코드에서 검사했으며 원본 함수의 바이트 그대로를 실행한 검사가 아닙니다. 실제 게임의 피해·표시·전투 밸런스와 렉 재발은 확인이 필요합니다. 게임 실행·패치 설치·성장 기록 초기화는 수행하지 않습니다.
