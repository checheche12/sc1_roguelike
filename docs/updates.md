## 1.0.22 — 2026-11-19

### 다음 회차

캠페인의 마지막 임무를 완료하면 로더의 **회차 관리 · 다음 회차…**에서 해당 캠페인을 첫 임무부터 다시 시작할 수 있습니다. 보유 재능과 획득 횟수를 이어받고, 새 회차에서 재능을 다시 뽑을 수 있습니다. 이전 회차의 선택과 완료 기록도 보관합니다. 선택한 캠페인의 마지막 임무를 완료하기 전에는 다음 회차 버튼이 잠겨 있습니다. 중간 분기의 모든 임무를 완료할 필요는 없습니다.

| 다음 회차 설정 | 적용 방식 |
|---|---|
| 기존 저주 | 초기화하거나 그대로 가져옵니다. 기본값은 초기화입니다. |
| 임무당 새 저주 | 0~4회 중 고릅니다. 0회를 골라도 가져온 저주는 유지됩니다. |
| N회차 보정 | 기본값은 켬입니다. 켜면 반복 획득 재능의 상한이 2회차에 +1, 3회차에 +2로 늘어납니다. 최대 상한은 255회입니다. 끄면 기본 상한을 적용하고, 초과 획득 기록은 보관합니다. 고유 재능은 한 번만 획득합니다. |

### 새 재능 시너지

| 조합 | 두 재능을 함께 보유했을 때 |
|---|---|
| 소환 균열 × 전장 소환문 | 아군이 소환문을 통과하면 도착 지점의 감속 균열 하나를 갱신합니다. |
| 정화 호위장 × 응급 처치 | 메딕이 체력 30% 이하인 생체 아군에게 리스토레이션을 적중시키면 응급 처치가 한 번 발동합니다. 기존 응급 처치와 비용·재사용 시간을 공유합니다. |
| 집행 저격 × 생체 신경 봉쇄 | 고스트가 직접 봉쇄한 적을 저격으로 처치하면 6타일 안의 적 하나에게 남은 봉쇄 시간을 한 번 전달합니다. |
| 충격 포격 × 충격 포낭 | 가디언의 포격에 휘말린 주변 지상 적도 2초간 느려집니다. |
| 도약 저글링 × 끝없는 갑각 분쇄 | 착지 후 1초 안에 첫 공격이 도약 대상에게 명중하면 방어력 감소를 두 번 적용합니다. |
| 위상 잔향 × 보호막 재충전 | 잔향으로 보호막을 회복하면 재충전 대기가 6초에서 3초로 줄어듭니다. 다시 피격되면 6초 대기를 시작합니다. |
| 위상 과부하 × 과부하 교란탄 | 교란탄으로 감속된 적에게 과부하가 발동하면 3타일 안의 다른 공중 적 하나에게 남은 감속 시간을 전달합니다. |

### 피해 계산과 전투 처리

- 근접 병력 피해 감소 교범은 중첩마다 남은 피해에 0.9를 곱합니다. 받는 피해는 2중첩에서 81%, 10중첩에서 약 34.9%입니다.
- 공세 병력이 등장할 위치를 고를 때 같은 배치 안에서 점유된 칸과 보호 구역을 반복 검사하던 작업을 줄였습니다.
- 전염성 방사선은 감염된 유닛만 갱신합니다. 이동 둔화 배율은 효과가 갱신되거나 만료될 때 다시 계산합니다.
- 강화 사이오닉 폭풍의 중첩 판정, 수송선 승객 확인, 일꾼 기습 대상 검색에서 같은 유닛이나 범위를 반복해서 확인하는 작업을 줄였습니다.
- 독립 교범의 획득 횟수와 임무 재접속 후 첫 선택의 기준 등급을 바로잡았습니다. 다음 회차로 가져온 저주가 많을 때에도 임무 보급 상자가 누적 수를 반영합니다.

## 1.0.21 — 2026-11-15

파이어뱃의 화염 이펙트와 재능 조합을 개선하고, 자원 재능을 개편했습니다. 부르드워 저그 첫 임무의 마지막 전투에서 적 무적이 풀리지 않는 문제도 수정했습니다.

### 파이어뱃

- **잔류 화염**에 지속 시간 동안 남는 화염 이펙트를 추가했습니다. 공격 방향과 불꽃 방향이 90도 어긋나던 문제를 수정했습니다.
- **지옥불 분사(부채꼴 공격)**에 전방으로 퍼지는 화염 이펙트를 추가했습니다.
- **잔류 화염 + 지옥불 분사**를 함께 보유하면 잔류 화염도 전방 **3타일·120도 부채꼴**로 남습니다. 발사 당시 위치와 방향을 기준으로 5초간 유지되며, 파이어뱃이 이동하거나 방향을 바꿔도 남은 화염은 따라 움직이지 않습니다.
- 여러 잔류 화염이 겹쳐도 같은 적에게 지속 피해가 중복으로 쌓이지 않습니다.
- **대공 화염 분사 + 지옥불 분사**는 공중 적을 조준할 때 주변 공중 적에도 부채꼴 피해를 줍니다. 지상 적을 조준하면 부채꼴도 지상에 적용됩니다. 대공 일반 공격 사거리는 5타일, 부채꼴 범위는 3타일·120도입니다.
- 세 재능을 함께 보유하면 공중 부채꼴 공격과 함께 발사 방향의 지상에도 부채꼴 잔류 화염을 남깁니다. 잔류 화염의 지속 피해는 지상 적에게만 적용됩니다.

### 자원 재능

| 재능 | 변경 내용 |
| --- | --- |
| 많은 자원 | 광물·가스의 남은 매장량이 3배가 됩니다. 같은 광물에서 아군 일꾼 2기가 동시에 채취할 수 있습니다. 한 번에 운반하는 자원량과 가스 동시 채취 인원은 바뀌지 않습니다. |
| 신속한 확장 | 새 기본 기지의 건설 시간이 50% 감소하고, 완공 시 해당 종족 일꾼 4기를 지원합니다. 일꾼 지원은 임무당 3회이며, 시작 기지와 레어·하이브 변태는 제외합니다. 다른 건설 시간 감소와는 곱연산으로 중첩됩니다. 기존 비용 할인은 제거했습니다. |
| 지게 채광지원 | 신규 선택지와 실행 효과에서 제거했습니다. 기존 기록의 재능 ID는 보존합니다. |
| 시간증폭 | 건물의 유닛 생산과 연구 진행 속도가 상시 25% 빨라집니다. 실제 작업이 진행 중일 때 적용됩니다. |
| 임무 보급상자 | 기존 효과를 유지합니다. |

### 임무 수정

- **에피소드 6 · 부르드워 저그 미션 1**: 마지막 하이브 전투에서 주황색 저글링·히드라리스크 등 적 병력의 무적이 남아 임무를 끝내지 못하는 문제를 수정했습니다. 마지막 전투가 시작된 뒤 해당 적 병력의 무적 해제를 반복 적용하며, 이전 연출 단계와 건물의 무적 처리는 유지합니다.
- **황무지**의 해병 10기 이상 조건과 마지막 보상·완료 응답 조건을 실제 엔진의 분리된 시험 지도에서 확인했습니다. 제보된 세션의 클리어 불가 증상은 재현하지 못했으므로 이번 버전에서 해당 제보가 완전히 해결됐다고 보장하지는 않습니다.

### 업데이트 방법

게임과 기존 관리자를 종료하고 새 ZIP을 **새 폴더**에 압축 해제한 뒤 `Start_Campaign.exe`를 실행하세요. 기존 성장 기록을 선택하고 **캠페인 패치 설치 / 업데이트**를 누른 다음 임무를 새로 시작하면 됩니다. 기존 성장 기록·재능·저주·임무 진행 기록은 이어서 사용할 수 있습니다. 임무 중간 세이브 불러오기는 지원하지 않습니다.

### 확인한 범위

실제 스타크래프트 엔진의 자동 시험에서 자원 재능 33개, 파이어뱃 지상 조합 85개, 방향·임무 조건 35개, 대공 조합 42개 검사를 통과했습니다. 해당 최종 시험 실행에서는 비정상 종료가 없었습니다. 네이티브 동작 검사 578개 그룹과 선택 UI 검사 22개 그룹도 통과했습니다.

전체 캠페인을 처음부터 끝까지 플레이한 결과는 아니며, 화면 외관을 직접 검수하거나 모든 환경에서 튕김이 없음을 보장하는 검사는 아닙니다.
