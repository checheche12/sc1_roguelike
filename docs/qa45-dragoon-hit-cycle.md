# QA45 드라군 누적 3타와 250% 추가 피해

과충전 위상탄은 드라군 한 기의 일반 공격 적중을 누적하여 세 번째 대상에 원래 공격의 250% 추가 피해를 준다. 기본 일반 공격 피해 +75%는 유지한다. 표적·지상/공중 공격층이 바뀌거나 공격을 중단해도 누적은 유지한다. 첫 두 타격의 대상이 죽어도 횟수에 포함하며, 세 번째 타격으로 대상이 죽으면 그 주기의 추가 피해는 끝난다.

누적은 드라군·영웅 변형 각각에 따로 보관하며 새 유닛 세대·소유자 변경 때 초기화한다. 추가 피해가 누적을 다시 올리거나 같은 발사체의 중복 콜백이 두 번 계산되지 않도록 기존 차단 경로를 사용한다. 저장 ID·선택 이력·동결 스냅샷과 다른 유닛 전설은 바꾸지 않는다.

프로덕션 호스트 검사에서 3·6타의 피해, 표적 교체와 긴 중단, 지상/공중 전환, 여러 드라군, 처치 타격, 중복·추가 피해 제외와 슬롯·소유자 경계를 실행한다. 실제 게임 체감은 별도 플레이 확인 대상이다.
