# QA35 인터셉터 일제 출격과 내구도

사용자 요청에 따라 ‘확장 인터셉터 격납고’의 16기 수용량 증가 효과를 교체합니다. 재능을 보유한 캐리어와 간트리서는 공격을 시작할 때 보유 인터셉터를 최대 8기까지 같은 프레임에 출격시킵니다. 아군 인터셉터의 최대 체력과 최대 보호막은 각각 정확히 2배입니다. 먼저 적용된 다른 체력·보호막 재능과도 함께 적용합니다. 캐리어 전설의 추가 대상 2기 효과는 유지합니다.

수용량은 원래 게임의 4기, 기본 용량 연구 후 8기를 따릅니다. 연구·생산 비용·생산 시간·다섯 칸 대기열은 원래 경로를 사용합니다. 생산 제한을 우회하기 위해 내부·외부 인터셉터 수와 연구 단계를 잠시 바꾸던 코드는 제거합니다. 기존 임무에서 이미 만들어진 초과 인터셉터를 삭제하지 않습니다.

일제 출격은 원래 게임이 표적과 사거리 등을 검사하고 실제 첫 출격을 수행한 경우에만 이어집니다. 같은 네이티브 명령 경로에서 발진 대기만 없애고, 실제 내부·외부 연결 목록의 이동을 매번 확인하며 최대 8기에 도달하면 멈춥니다. 남은 병력이 없거나 네이티브 출격이 거절되거나 소유권·유닛 정체성이 바뀌면 중단합니다. 새 인터셉터를 무료 생성하거나 링크·수량을 직접 조작하지 않습니다. 기존 출격 속도 재능은 함께 보유했을 때의 대기 시간에 적용합니다.

재능 ID와 비트 368은 유지합니다. 과거 재능 보유 기록은 새 효과를 사용하며 이후 설명만 새 내용으로 갱신합니다. 이미 발급된 선택 후보와 확정 스냅샷, 사용자 입력 원문은 보존하므로 과거 후보에는 예전 설명이 남을 수 있습니다.

오프라인 프로덕션 호스트 검사는 0~8기·부분 출격·영웅·적/동맹/중립·환영·출격 속도 조합, 원래 비용·시간·생산 상한, 내부/외부 수량과 연구 단계의 비변경, 기존/새 인터셉터 내구도와 표시 상한, 다른 체력 재능과의 중첩을 확인합니다. 임시 SQLite 기록으로 과거 16기 설명의 발급 후보 보존과 새 설명 갱신도 검사합니다. 실제 새 DLL의 출격 연출·전투 체감·HD/SD 외관은 플레이 검증 대상입니다.

QA34의 공통 범위 이펙트 렌더러 수정도 포함합니다. 사용자 요청에 따라 이전 로컬 QA 실행 폴더와 ZIP을 정리하고 QA35만 남깁니다. 성장 기록·사용자 입력·검증 증거는 보존합니다.
