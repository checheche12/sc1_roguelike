# QA48 체력 저주 누적 완화

임무가 쌓인 뒤 드라군 두 기가 체력 288의 뮤탈리스크 한 기에게 패배했다는 플레이 피드백을 반영한다. 사용자는 버그가 아니라 실제 교전의 밸런스 문제라고 정정했다.

체력 저주가 추가 공세 병력의 체력·보호막에 더하는 수치를 절반으로 낮춘다.

| 중첩 | 이전 누적 증가 | 변경 누적 증가 |
|---|---:|---:|
| 1 | +20% | +10% |
| 2 | +44% | +22% |
| 3 | +72% | +36% |
| 5 | +140% | +70% |
| 10 | +380% | +190% |

중첩별 증가량은 +20/+24/+28%…에서 +10/+12/+14%…로 바뀐다. 기본 체력 120인 일반 뮤탈리스크는 5중첩에서 288 대신 204 체력을 가진다. 정예·특수 편성의 별도 보정은 각 편성에 따라 적용된다.

기존 카드 ID, 중첩 수, 임무 진행, 이미 발급한 선택지·스냅샷은 보존한다. 기존 기록은 다음 연결 시 해당 저주의 현재 설명·효과 메타데이터만 갱신한다. 게임 실행 중인 전투를 변경하지 않으며, 업데이트 후 새로 시작하는 임무부터 적용한다.

재능과 나머지 저주의 수치는 QA47과 같다. QA46 전설 기본 강화 완화, QA47 기존 기록 선택과 선행 임무·진행 상황 안내도 포함한다.

검증은 임시 기록의 이전 버전 갱신, 전송 중첩 보존, 네이티브 생성 체력·보호막·표시 값과 기존 회귀 검사로 수행한다. 실제 교전 승패와 장기 난이도는 사용자 플레이로 확인해야 한다.
