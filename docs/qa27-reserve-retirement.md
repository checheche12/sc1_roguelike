# QA27: 후속 예비대 삭제

후속 예비대도 일반 저주로는 누적 공세 부담이 지나치게 커 사용자의 지시로 삭제했다. 끈질긴 후미대와 함께 새 선택 후보에서 제외하고, 이미 보유한 24·25번 저장 위치의 값은 효과를 발동하지 않는다. 선택을 기다리는 옛 후보는 원문과 UUID를 보관한 뒤 다시 발급한다.

후속 예비대의 15초 출발 예약·생성·경고 경로를 제거했다. 기본 공세의 20% 예산 강화, 증원·공격·체력의 증가하는 무한 중첩, 일꾼 공습 2/6/10기·최대3회, 캠페인 중반 전설 저주 해금과 전설 재능 네 가지 보완은 QA26대로 유지한다.

새로 만든 성장 기록은 보존한다. 이전 기록을 다시 지우거나 게임을 자동 실행하지 않는다. 검증은 임시 DB 선택 회귀 검사와 네이티브 호스트·UI·프로토콜 검사이며, 실제 전투는 새 임무 플레이로 확인한다.
