# QA50 공중 기본 공세 수량 조정

기본 공세가 공중 편성일 때 전투 병력 예산을 기존의 80%로 줄인다. 테란·저그·프로토스 모두 동일하게 적용한다. 실제 기수는 병종별 인구 비용과 정수 반올림에 따라 달라진다.

물량 저주 및 기존 수량 배율을 계산하고 탐지기 예산을 확보한 뒤, 공중 편성의 전투 병력 예산에 한 번 적용한다. 같은 기본 편성을 사용하는 사망 지원 병력에도 적용하며 저장된 원래 예산을 덮어쓰지 않는다.

지상·혼성 기본 편성, 원본 임무 병력, 별도 저주 특수 편성, 일꾼 습격의 수량 및 탐지기 수는 유지한다. QA48 체력 저주와 QA49 공격력 저주 완화, 성장 기록 형식도 유지한다.

실제 생성 어댑터를 이용한 세 종족의 초기·중기·후기 편성과 물량 중첩 검사, 공중 지원 병력의 중복 감소 방지 검사, 전체 기존 네이티브 및 패키지 검사를 수행한다. 실제 게임 전투 체감은 사용자 플레이로 확인한다.
