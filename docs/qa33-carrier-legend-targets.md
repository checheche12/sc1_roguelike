# QA33 캐리어 전설과 공세 보호막

캐리어 전설의 인터셉터가 주변의 다른 적 1기 대신 2기를 추가 공격합니다. 원래 표적을 포함해 최대 3기를 때리며 각 대상에게 원래 공격의 100% 피해를 줍니다. 추가 표적은 서로 다른 공격 가능한 적으로 제한하며, 적이 부족하면 존재하는 표적만 공격합니다. 추가 타격은 새로운 추가 공격을 만들지 않습니다.

관리자와 네이티브 선택창 설명·효과 메타데이터를 갱신합니다. 공통 전설 배율을 올리는 대신 이 능력의 추가 대상 수만 2기로 지정합니다. QA32 뮤탈리스크 전설의 두 발 각각 100%, 다른 전설·교범 수치는 유지합니다. 재능 보유 상태, 확정 스냅샷과 이미 제시한 선택 후보 원문은 보존하므로 과거 후보에는 1기 설명이 남을 수 있습니다. 업데이트한 DLL의 실제 공격은 추가 2기를 사용합니다.

‘악마의 생명력’ 저주는 추가 공세의 최대 보호막에도 최대 체력과 같은 +8%, +12%, +16%… 증가분을 적용합니다. 1·2·3중첩 누적은 각각 +8%·+20%·+36%입니다. 생성 시 증가한 보호막을 채우고, 유닛별 네이티브 명령·타이머의 재생 상한과 선택창 최대 보호막 표시를 일치시킵니다. 원래 지도 병력·아군·중립·환영은 제외합니다. 체력만 늘리는 다른 편성·정예 보너스는 보호막에 추가로 곱하지 않습니다. 보호막이 원래 없는 유닛에는 새 보호막을 만들지 않습니다. 16비트 네이티브 최대 보호막의 한계인 65,535에서 포화 처리하며 저주의 선택 상한은 추가하지 않습니다.

렌더링 스레드는 유닛 생성 번호·소유자·종류와 함께 게시한 보호막 값을 읽습니다. 그리기 중 전역 DAT를 수정하지 않습니다. 소유권 이전 시 남은 보호막 비율을 유지하면서 공세 전용 증가분을 제거합니다. 원래 보호막 수치는 성장 적용 전에 고정해 중첩된 유닛별 DAT 범위가 다른 병력에 영향을 주지 않게 합니다.

기존 네이티브 전투 검사에서 전설 미보유 시 1기, 보유 시 서로 다른 적 3기에 원래 피해를 주는지와 아군·공격 불가능한 표적 제외, 추가 공격의 재귀 생성 방지를 검사합니다. 보호막은 0~3중첩·255 초과·큰 중첩, 일반·영웅·공중 병력의 생성·표시, 중첩된 DAT 범위, 모의 네이티브 재생 콜백, 소유권 이전·슬롯 재사용·환영·비활성 보호막을 검사합니다. 모의 콜백은 실제 게임의 타이머 명령어 실행 검증과 구분합니다. 카탈로그·전설 꾸러미·설명 갱신·패키징 회귀 검사도 수행합니다. 지도는 기존 63개와 같고 사용자 기록 수정·게임 실행·패치 설치는 수행하지 않습니다. 실제 전투 체감은 플레이 검증이 필요합니다.
