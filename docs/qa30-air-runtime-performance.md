# QA30 공중 유닛 점검과 런타임 최적화

스카우트의 지상·공중 무기와 영웅, 가디언·디바우러의 사거리·이속·체력·화력 교범 적용을 대조했습니다. 첫 공중 강화의 사거리 1타일과 이동 속도 20%는 여러 번 선택해도 중첩되지 않습니다. 뮤탈리스크·스커지는 이 기동 보너스에서 제외하며, 기존 전설 수치와 자폭·튕김 처리를 유지합니다. 퀸·아비터·수송·탐지 유닛의 기존 마법·수송·표시 회귀 검사도 포함합니다.

함대 동체 강화에 커세어·라자갈의 대공 사거리 1타일을 추가합니다. 이동 속도와 피해는 추가하지 않고, 디스럽션 웹의 사거리를 바꾸지 않습니다. 과거 커세어 전용 사거리 재능의 영웅 제외 규칙은 별도로 유지합니다. 캐리어·간트리서는 직접 무기 슬롯이 없으므로, 무기 사거리 대신 네이티브 교전·출격 판단에 쓰는 획득 거리 값을 8에서 9타일로 수정합니다. 인터셉터 공격력이나 한도를 추가로 올리지 않습니다.

커세어 과부하 교란탄은 일반 공격의 발사 순서를 탄마다 저장해 네 번째 공격을 판정합니다. 기존에는 명중 당시의 현재 발사 횟수를 읽어 빠른 연속 발사나 웹 시전이 판정을 바꿀 수 있었습니다. 추가탄·마법은 횟수에 포함하지 않으며, 늦거나 순서가 바뀐 명중도 검사합니다.

저그·프로토스 공중 강화의 최신 QA 번호를 과거 체력 보정 코드가 덮어쓰던 문제를 수정합니다. 기존 기록의 이후 후보 설명과 메타데이터가 갱신되며, 이미 제시된 후보 원문과 확정 스냅샷은 보존합니다. 실제 사용자 기록은 수정하지 않습니다.

런타임 최적화는 다음 경로를 다룹니다.

- 주변 탐색은 필요한 수의 가장 가까운 대상을 먼저 추리고 그 부분만 정렬합니다. 거리·동률 순서·소유자·공중/지상·생체 필터를 원래 전체 정렬 결과와 대조합니다. 위치나 소유자가 바뀌면 매번 현재 값을 읽습니다.
- 네이티브 사거리·시야·획득 거리 조회는 필요한 DAT 필드만 소유자별로 적용합니다. 명령·피해·생성·변태는 전체 DAT 뷰를 유지합니다. 중첩 소유자 조회, 영웅 제외, 환영, 다음 성장 단계 갱신과 원상 복구를 검사합니다.
- 공통 유닛 순회의 중복 검사 배열을 중첩 깊이별로 재사용합니다. 중첩 호출과 예외가 바깥 순회의 상태를 덮어쓰지 않는지 검사합니다.
- 애벌레는 한 번의 순회로 해처리별 수를 집계합니다. 적 소유와 다른 해처리의 애벌레를 섞지 않으며 기존 생성 타이머·상한을 유지합니다.
- 추가탄 대기 큐의 두 버퍼를 재사용하고, 이미 명중한 투사체의 기록은 재추적 대상 탐색을 건너뜁니다. 취소·사망 대상과 다음 프레임 처리 순서는 유지합니다.
- 에너지 표시에서 값이 같으면 원자적 쓰기를 생략하고, 가상 최대 에너지 재능이 없으면 해당 캐시 갱신을 생략합니다. 변경된 에너지와 오래된 유닛 식별자는 기존 검사로 확인합니다.

240 활성 프레임마다 남기는 `PERF runtime` 로그에 DAT 스코프·조회 수, 적용 항목·오버라이드 수, 주변 탐색 수, 투사체 기록·대기탄 수를 더합니다. 공세·AI는 기존 주문 배치와 주기를 유지하며 적 마법사의 대규모 탐색 검사도 실행합니다. 체력·수송·생산 표시 등의 현재 비용도 모의 병력에서 측정합니다.

성능 수치는 게임 FPS가 아닌 오프라인 프로덕션 코드 측정입니다. 1,600기 조건에서 사거리 조회 1,600회, 넓은 주변 탐색 400회, 해처리 32개 집계 등의 동일 작업량을 비교합니다. 실제 게임의 렉 해소와 렌더링·경로 탐색 비용은 새 로그와 사용자 플레이로 확인해야 합니다. 게임 실행·패치 설치·성장 기록 초기화는 수행하지 않습니다.
