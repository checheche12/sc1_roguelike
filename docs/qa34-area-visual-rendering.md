# QA34 범위 강화 이펙트 표시 수정

HD 사이오닉 스톰의 범위 강화가 화면에 나타나지 않는 제보를 확인했습니다. QA33 실제 실행 로그와 읽기 전용 렌더러 진단에서 확대 성공 0회, 거절 4,066회를 확인했습니다. 게임 실행과 선택 기록을 유지한 채 해당 프로세스의 렌더러 데이터만 읽었습니다.

QA31의 공통 확대 코드는 다음 그리기 명령의 시작 위치와 예약된 정점 수로 정점 간격을 추측했습니다. 실제 HD 렌더러는 1,024개 정점을 예약한 묶음의 사용하지 않는 꼬리를 반환하고 다른 이미지에 재사용합니다. 예약 공간의 중간에 다른 명령이 들어오거나 정렬 여백이 생기면 간격을 잘못 계산하며, 새 명령이 이전 버퍼 끝보다 앞에 생기는 정상적인 재사용도 거절했습니다. 이전 합성 검사는 빈 공간이 없는 작은 버퍼만 사용해 이 문제를 찾지 못했습니다.

지원하는 1.23.10.13515의 셰이더 입력 형식 43종과 네이티브 할당기의 속성 크기를 기준으로 정점 간격을 구합니다. 예약 공간과 정렬 여백으로 간격을 추측하지 않습니다. 해당 이미지가 이번에 작성한 좌표만 확대하고, 다른 이미지가 실제 사용 중인 정점과 겹치거나 알 수 없는 형식이면 전체 변경을 취소합니다. 텍스처 좌표, 색상, 인덱스, 이전 이미지와 남은 빈 공간은 보존합니다.

공통 경로의 스톰·EMP·인스네어·스테이시스·마엘스트롬·다크 스웜·디스럽션 웹·아콘 타격·전설 이레디에이트가 대상입니다. 게임에서 범위 강화가 있는 효과만 기존 소유자·시전자·계보 정책대로 확대합니다. 피해량·판정 범위·중첩·성장 기록은 변경하지 않습니다.

회귀 검사는 실제로 관찰한 예약 꼬리 재사용과 배치 추가, 정렬 여백, 기존 정점과의 충돌, 지원하지 않는 형식, 17개 효과 이미지의 HD 정규화 좌표, 실제 등록 콜백을 통한 재사용을 다룹니다. QA33 코드에서 재현 검사 실패를 먼저 확인한 뒤 수정 코드로 통과시켰습니다. 기존 SD 형식과 소유자 분리 검사도 함께 수행합니다.

이 검사는 실제 화면 캡처나 HD/SD 외관 검증을 대신하지 않습니다. 사용자 게임은 종료·재시작하지 않으며, 새 DLL의 실제 화면 크기와 화면 가장자리 동작은 업데이트 후 플레이 확인이 필요합니다.
