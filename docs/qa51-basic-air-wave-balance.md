# QA51 공중 기본 공세 추가 완화

**상태: 추가 15% 감소는 사용자 요청으로 롤백했습니다. 현재 기준은 QA50의 공중 기본 공세 예산 80%입니다.**

사용자 피드백에 따라 공중 기본 공세의 전투 병력 예산을 QA50보다15% 더 줄인다. 최초 예산의80%에서68%로 조정하며, 중복 반올림 없이 최종 예산에 한 번 적용한다. 실제 기수는 병종별 인구 비용과 정수 반올림에 따라 달라진다.

QA50의 적용 범위를 유지한다. 지상·혼성 기본 공세, 탐지기, 별도 저주 특수 편성, 일꾼 습격과 원본 임무 병력은 유지한다. 같은 기본 편성을 사용하는 공중 사망 지원 병력에도 새 예산을 적용한다.

기존 QA48 체력 저주·QA49 공격력 저주 완화와 성장 기록 형식을 유지한다. QA50과의 생성 비교, 기존 네이티브 검사와 패키지 검사로 검증하며 실제 전투 체감은 사용자 플레이로 확인한다.
