# QA32 뮤탈리스크 전설 피해 조정

뮤탈리스크 전설의 쐐기벌레 두 발을 각각 원래 공격의 240%에서 100%로 낮춥니다. 첫 대상에 대한 두 발의 합계는 480%에서 200%가 됩니다. 각 발이 따로 튕기며 튕김 피해가 감쇠하는 동작은 유지합니다. 뮤탈리스크와 쿠쿨자(뮤탈리스크)의 아군 공격에 적용하며, 다른 전설과 교범 수치는 바꾸지 않습니다.

이 효과는 공통 전설 배율을 다시 곱하지 않고 각 탄환에 100%를 직접 지정합니다. 관리자 설명과 네이티브 선택창 설명도 함께 갱신합니다. 기존 기록의 재능 보유 상태와 확정 스냅샷, 이미 제시한 선택 후보 원문은 유지합니다. 이전에 제시한 후보에는 240% 설명이 남을 수 있으나 업데이트한 DLL의 실제 공격은 100%를 사용합니다.

검증은 프로덕션 네이티브 코드의 기본탄·추가탄 배율, 기존 전투·선택 UI·전송 회귀 검사와 임시 기록에서의 설명 갱신·기존 후보 보존 검사입니다. 지도는 QA31과 같은 63개이며 설치·게임 실행·사용자 데이터베이스 수정은 수행하지 않습니다. 실제 전투 체감은 플레이 검증이 필요합니다.
