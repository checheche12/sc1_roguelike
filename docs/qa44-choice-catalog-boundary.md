# QA44 재능 전송 제한으로 승리가 대기하는 문제 수정

QA43 프로토스 첫 임무에서 원래 목표는 달성됐고 성장 1·2단계도 적용됐다. 3단계 선택지를 전송할 때 `Choice candidate is not supported by this map catalog` 오류로 연결 프로그램이 종료되어, 게임이 나머지 성장 단계와 승리 승인을 기다렸다.

소유 비트 배열은 512비트지만 현재 논리 재능 목록은 560개다. 뒤에 추가된 유닛별 성장은 별도의 작은 저장 필드를 사용하며 네이티브 선택창도 560개를 지원한다. 연결 코드만 후보 번호의 상한을 512로 고정하고 있었다. 실제 임무 후보 552·495·558·555를 생성해 같은 오류를 재현했다.

재능 후보 번호는 현재 검증된 카탈로그 길이까지 허용한다. 소유 비트 크기, 저장 필드, 재능 ID, 이미 발행한 선택지와 확정 스냅샷은 바꾸지 않는다. 카탈로그를 벗어나는 번호와 잘못된 묶음은 계속 거부한다.

드라군 전설 과충전 위상탄은 같은 적을 4회 공격할 때마다 600% 추가 피해에서 3회마다 450% 추가 피해로 바꾼다. 기본 일반 공격 피해 +75%는 유지한다. 현재 카탈로그·저장 카탈로그의 향후 표시와 실제 네이티브 수치를 함께 갱신한다.

검증은 실제 후보 추첨·512 경계와 마지막 ID·묶음 보조 번호·범위 밖 거부, 모의 네이티브 프로토콜과 임시 기록의 전체 성장·완료 승인·재접속을 포함한다. 드라군과 영웅 변형의 첫 두 타격에는 발동하지 않고 3·6번째 타격에 각각 450%가 추가되는 것도 검사한다. 플레이어 DB를 열거나 수정하지 않는다. 수정된 실행기를 통한 실제 게임 완료 확인은 별도 사용자 플레이가 필요하다.
