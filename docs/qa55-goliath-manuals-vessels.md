# QA55 골리앗·일반 교범·공세 베슬

- 골리앗 전설은 주 대상에게 100%, 주 대상의 3타일 안 같은 공격층의 적 최대 3기에게 각각 50% 피해를 줍니다. 기존 전설의 단일 피해 +100%는 제거했습니다. 시야·무기 사거리·적대 조건을 만족한 적만 추가 공격합니다. 대공 미사일 두 발은 각 추가 대상에게도 두 발로 전달하며 추가탄은 재발동하지 않습니다.
- 새 일반 유닛 교범은 서로 다른 유닛 계열 3개를 무작위로 묶습니다. 한 번 확정하면 세 교범을 모두 받고 각 중첩이 함께 올라갑니다. 기존 일반 교범의 4중첩 상한과 과거 병과 교범·탄약 계열의 합산 규칙은 유지합니다. 전설과 고급·희귀·영웅 유닛 재능은 기존 두 계열 묶음을 유지합니다.
- 이미 발급된 단독·두 유닛 선택지는 저장된 구성 그대로 읽습니다. 세 유닛 묶음은 각 설명을 차례로 확인하고 한 번의 선택으로 저장합니다. 관리자와 네이티브 선택창은 동일한 세 구성원을 검증합니다.
- 경제 탭의 재능은 별도의 경제 지급에서 항상 한 개씩 획득합니다. 특정 유닛을 대상으로 해도 이 규칙을 따릅니다. 「쌍둥이 일벌레」·「탄약 생산 공정」·「건설 효율화」·「소환 공정 개선」도 모두 단독 지급하며, 전투 재능 묶음의 구성원으로 들어가지 않습니다. 이미 발급된 선택지의 저장 구성은 유지합니다.
- 「정밀 핵 유도」는 고스트, 「반중력 발사대」·「요격기 보조 화력」은 캐리어, 「갑충 파편탄」은 리버의 전투 강화 묶음에 포함합니다. 본체와 핵·인터셉터·스캐럽을 함께 대상으로 지정한 경우에도 같은 유닛 계열로 취급합니다.
- 추가 공세로 생성한 사이언스 베슬·해당 영웅은 생성부터 에너지 0을 유지합니다. 에너지 회복 전후와 명령 실행 시 다시 제한해 EMP·이레디에이트·디펜시브 매트릭스를 포함한 주문을 막습니다. 원본 지도 베슬과 플레이어에게 넘어온 베슬은 이 제한의 대상이 아닙니다. 탐지·이동은 유지합니다.
