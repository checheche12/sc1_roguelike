# QA40 효과 설명과 교범 정리

효과 설명 217개에서 없는 효과의 나열, 재귀·중복 처리 설명, 기존 설계와의 비교, 반올림 등 내부 구현 설명을 제거한다. 수치·발동 조건·시간·중첩 한도는 보존한다. 단일 공격·정지 중 사격 같은 유효 조건은 간결하게 표시한다. 효과 설명 전용 갱신 번호를 사용하며 실제 효과 메타데이터는 바꾸지 않는다.

SCV·드론·프로브 화력 교범과 드롭십·오버로드·셔틀 생존 교범을 신규 제안에서 제외한다. 활성 교범은 생존 41개·화력 31개, 합계 72개다. 영구 ID와 저장 필드는 유지하고 이미 보유한 성장의 저장·효과도 보존한다. 삭제한 교범이 포함된 미선택 제안은 원문을 보관한 뒤 다시 발급한다.

게임 선택창의 정적 설명, 관리자에 표시되는 저장 선택지, 현재 카탈로그, HTML을 함께 정리한다. 저장 선택지의 JSON과 확정 입력·동결 스냅샷은 덮어쓰지 않는다. 이전 카탈로그를 사용하는 메모리 DB에서 설명 갱신·원문 보존·65워드 소유권 호환을 검사한다. 네이티브 헤더 변경은 효과 문자열 배열에 한정되는지 비교한다.
