# QA38 유닛 전용 성장과 전설 확장

44개 생산·소환 유닛 계열 모두에 종족 전설이 있다. 영웅 변형은 기본 계열을
계승한다. 기존 영웅 화력 특성 21개는 수치를 그대로 두고 전설로 승격했으며,
각 자리에 더 낮은 화력의 새 영웅 특성을 넣었다. 새 종족 전설 15개를 추가했고
정신감염은 비활성화했다. 총 전설은 공통 3개와 종족 51개다.

체력·보호막 교범 44개와 공격 가능한 유닛의 화력 교범 34개를 추가했다.
유닛별 고급·희귀·영웅 특성도 44개 추가했다. 유닛 전용 일반·고급·희귀·영웅은
전설과 같이 같은 등급의 서로 다른 유닛 2개를 한 선택지로 묶어 둘 다 지급한다.
공통 특성과 여러 유닛에 적용되는 특성은 단독 선택이다. 기존 광역 체력·화력
교범은 새 제안에서 제외하고 이미 보유한 효과와 발급 선택지는 보존한다.
기존 병과 교범과 유닛별 교범은 합쳐 최대 4중첩이다. 캐리어/요격기와
리버/스캐럽의 화력은 높은 단계 하나를 적용하고 다음 선택은 그보다 한 단계
높아진다. 공격하지 않는 유닛에는 화력 교범을 만들지 않았다.

전설 보장 4칸은 선택 가능한 공통 전설이 있으면 1/3 확률로 공통 1칸을
제시한다. 나머지는 종족 선택지다. 평상시 등급 확률은 그대로다.

야마토 실제 원본 엔진의 에너지 배열 읽기를 소유자 범위로 연결해 시전 전 검사,
차감, 표시 모두 50으로 맞췄다. 봉쇄 반경 6타일/총 7기, 정신 지배는 인구 제한
없이 총 5기다. 전장 소환문은 영웅이며 첫 리콜과 문을 지난 아군에 30초간
일반 공격 피해 +20%를 준다. 재통과는 시간만 갱신한다.

방사선 전염은 6타일이며 기계에도 피해를 주는 별도 영웅을 추가했다. 다크 스웜은
초당 최대 체력 3%를 회복한다. 브루들링은 대상당 6기, 주변 4타일의 유효 대상
3기에도 추가로 시전해 최대 24기를 만든다. 플레이그는 네이티브 고정 반경의
2배에 실제 타격을 재생한다. 재능 없는 원래 시전은 그대로다.

일반 추가 공세는 이전 편성 대비 15%, 희귀 50%, 영웅 75%, 전설 100% 늘어난다.
영웅 유닛 수도 포함한다. 작은 편성은 정수 반올림하며 최초 시각·주기·임무 제외·
동시 인구 상한은 유지한다. 저주 중첩 증가분은 물량과 체력/보호막이 회차별
20/24/28…%, 공격력이 15/19/23…%, 공격/이동 속도가 15/16/17…%다.
3회 누적은 각각 72%, 57%, 48%다.

기존 437비트, 교범 21워드, 저주 확장 카운터 4워드는 변경하지 않는다. 새 유닛
성장은 비어 있던 교범 21~27워드와 소유 비트 437 이후에 명시적인 작은 필드로
저장한다. 실제 전송은 기존 65워드, 지도 63개도 그대로다. 새 논리 카드 번호를
그대로 소유 비트 번호로 쓰지 않는다. 3→4단계에서 바뀌는 비트의 단조성은
논리 단계로 검증한다. 전체 묶음의 유효성을 검사한 뒤에만 기록한다.

검증은 프로덕션 C++ 호스트, UI/프로토콜 실행 검사와 임시 DB 기반 Python 검사다.
실제 새 게임·모든 전투 조합·밸런스·HD 외관·성능 검증은 별도 사용자 플레이가
필요하다. 개인 DB, 수정 원문, 확정 입력, 발급 선택지, 동결 스냅샷은 덮어쓰지
않으며 설치·게임 실행·공개 배포는 수행하지 않는다.
