QA65는 256×256 통합 효과 시험장을 추가하고 대공 지정 공격과 추가 공격 누락을 수정합니다.

QA66은 생성 중 즉시 명중하는 추가 투사체에도 50% 피해 배율을 적용하도록 보완합니다. 히드라 추가탄과 러커의 즉시 명중 대공 공격을 별도 회귀 검사로 확인하며, 아래 시험장과 균형 변경을 모두 포함합니다.

QA67은 실제 엔진 시험에서 확인된 공격층 문제를 수정합니다. 발키리의 전설 지상 공격은 지상에만 스플래시를 주며, 파이어뱃이 얻은 대공 공격은 공중에만 적용됩니다. 러커의 공중 가시는 공중 적에게 실제 피해를 주고 계속 반복 발사합니다. A로 적을 직접 지정하는 공격과 적 우클릭을 모두 처리합니다.

전설 다크 스웜은 기존 가로·세로의 절반인 반경 5타일로 줄였습니다. 보호·회복 판정과 화면 배율이 같은 범위를 사용하며 아군 공중 보호와 초당 최대 체력 3% 회복은 유지합니다. 시험장에 놓인 적 SCV와 새 시험 표적은 홀드를 유지합니다. 마인 반응 시험은 적 마린을 사용하고, 일꾼은 반응하지 않는 대조군으로 사용합니다.

ZIP 압축을 풀고 `Start_Effect_Lab.cmd`를 실행해 `x86_64/StarCraft.exe`를 선택합니다. 게임에서 싱글 플레이 → 사용자 지정 게임 → `SC1_Roguelike/SC1_Effect_Lab.scx` → 유즈맵 설정으로 시작합니다. 시험 맵 실행기는 캠페인 기록을 열지 않습니다. 사용자가 실행기를 누를 때 시험 지도만 Maps 폴더에 복사합니다.

`Effect_Checklist.html`에서 재능 561개·저주 50개를 검색하고 적용 명령을 복사할 수 있습니다. 과거 호환 항목과 사용 중단 항목도 구분해 표시합니다. 실제 전투에서 확인한 항목에만 체크하면 브라우저에 보관됩니다.

채팅 명령:

| 명령 | 기능 |
|---|---|
| `-t 번호 단계` / `-c 번호 중첩` | 재능 / 저주 개별 적용·조합. 단계·중첩 0은 해제 |
| `-clear` / `-reset` | 효과 해제 / 효과와 이동 병력 재생성 |
| `-case 1` / `2` / `3` / `4` | 히드라 / 러커 / 뮤탈 / 가디언 시험 세트 |
| `-case 5` / `6` / `7` / `8` | 마법 / 타워 / 수송 / 근접·스플래시 시험 세트 |
| `-spawn 유닛ID 수 소유자` | 유닛 추가. 아군 0, 적 6, 한 번에 최대 50기 |
| `-heal` / `-hurt` | 체력·보호막·에너지 회복 / 아군 체력·보호막 절반 |
| `-up 업그레이드ID 단계` | 업그레이드 비교. 예: 터렛 8, 스포어 11, 캐논 13 |
| `-race 1` / `2` / `3` | 테란 / 저그 / 프로토스 캠페인 문맥 |
| `-wave` | 현재 저주로 생산 코드의 추가 공세 구성 강제 생성 |

시험 세트는 (75,75) 타일 근처에 생성됩니다. 러커는 직접 잠복해야 합니다. 시작 효과는 종족 문맥을 고른 뒤 `-clear` 후 재적용하고, 생산비·수송·탄약 효과는 새 유닛으로 비교합니다. 업그레이드·이미 지은 건물·지도의 전체 초기 상태는 임무를 다시 시작하면 복원됩니다.

권장 확인 순서:

1. `-clear`, `-t 256 1`, `-t 335 1`, `-case 2`: 러커 잠복 후 공중 적 A 클릭과 우클릭, 지상·공중 관통 대상별 추가 50% 타격.
2. `-clear`, `-t 256 1`, `-case 1`: 히드라 기본 공격과 추가 공격. 단독 전설 `-t 328 1` 조합도 확인.
3. `-clear`, `-t 343 1`, `-case 3`: 뮤탈 피해 +100%, 최대 6번 튕김. 최초 명중 기준 7/7→6/7→…→1/7. 다른 튕김 재능과 조합해도 최대 6번.
4. `-clear`, `-t 429 1`, `-case 4`: 가디언 직격 +150%, 3타일 내 다른 지상 적 최대 6기에도 강화된 공격의 100% 피해.
5. `-clear`, `-t 560 1`, `-case 6`: 타워 강화 1회·2회, 업그레이드 전후와 캐논 지상·공중 비교. 이 재능의 일반 후보 내 가중치는 3배이며 효과·최대 2회는 유지.
6. `-clear`, `-t 271 1`, `-t 312 1`, `-t 353 1`, `-case 7`: 드롭십·오버로드·셔틀 속도 +40%. 수송 공간 확대 효과는 제거되어 기본 공간을 사용.

히드라처럼 생성 도중 명중하는 투사체는 첫 피해 전에 발사 정보를 등록합니다. 러커는 엔진의 공격자별 중복 가시 방지에 막히지 않도록 관통한 각 적에게 네이티브 무기 피해 50%를 한 번 추가합니다. 추가 공격이 다시 추가 공격을 만들지 않습니다. 새 공격층의 명중 횟수·명령 판정·탄착 공격층도 함께 처리하며, 파이어뱃의 전방 공격은 공중 공격을 얻은 경우 같은 공중층을 따릅니다.

검증: 실제 SC:R 엔진에서 재능 561개·단계 조합 859개 적용/해제와 최대 체력 666개 검사를 통과했습니다. 16개 공격 상황을 동시에 실행해 A 지정·우클릭, 추가탄 조합, 반복 공격, 아군·반대 공격층 제외와 표적 홀드를 확인했습니다. 전설 다크 스웜도 실제 시전 후 반경 160픽셀과 안/밖의 보호·회복 차이를 확인했습니다. 177개 유닛 특수/마법 상황의 병렬 실행 로그는 별도 분석 중이며 전체 조건 통과를 뜻하지 않습니다. 화면 캡처 검증은 완료되지 않았습니다. 기존 캠페인 63개 지도와 별도 시험 지도의 구조는 유지됩니다.
