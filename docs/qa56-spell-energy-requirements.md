# QA56 시전 에너지 조건 수정

고효율 시전·효율적 군체 마법·정교한 시전·절약된 리콜은 실제 에너지 차감량을 줄이고 있었지만, 시전 전 검사는 원래 비용을 요구했습니다. 마우스 대상 선택의 별도 에너지 검사와 명령 처리·실제 시전 검사를 함께 보완했습니다.

- 고효율 시전: 원래100 에너지인 주문은40으로 시전할 수 있습니다.
- 정교한 시전: 사이오닉 스톰75는37.5로 시전할 수 있습니다. 소수점 에너지를 정수로 올려 요구하지 않습니다.
- 절약된 리콜: 비용이0이 되면 에너지0에서도 시전할 수 있습니다. 정교한 시전과 함께 있어도 에너지를 추가로 돌려받지 않습니다.
- 기존 감소율과 실제 차감량을 유지합니다. 시전 취소·잘못된 대상·사거리 부족으로 주문이 실행되지 않으면 에너지가 늘어나지 않습니다.
- 적·환영·미보유 재능은 기존 조건을 사용합니다. 추가 공세 베슬의 에너지0 제한도 유지합니다.

네이티브409그룹1,555,705검사와 선택창22그룹174,882검사를 통과했습니다. 원래 엔진의 에너지 비교 명령과 새 연결 코드를 복사한 실행 검사로 경계값을 확인했습니다. Python 관리자·카탈로그 코드가 그대로이므로 이전76개 검사 결과를 유지하고 Python↔네이티브 저장 연동은 새로 실행했습니다. 실제 게임 화면·임무 완주 검증과는 구별합니다.
