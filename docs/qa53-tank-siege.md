# QA53 추가 공세 전차 공성 모드

추가 공세의 전차는 이동·공격 명령만 받았으며 공성 모드 전환 판단이 빠져 있었다. 전차와 듀크가 공격할 수 있는 지상 적을 만나면 원본 전개 명령(98)을 내린다. 원본 무기의 최소·최대 사거리와 유닛 충돌 크기를 사용하며, 시야·은폐 탐지·네이티브 공격 가능 판정을 통과한 표적만 고른다.

전개한 전차는 원본 공격 명령으로 포격한다. 적이 사라지면 마지막 접촉 후 3초, 최소 사거리 안의 적만 남으면 1초 후 해제 명령(99)을 내린다. 모드 전환 명령 후 3초 동안은 다시 전환하지 않는다. 해제가 완료되면 기존 공세 이동 처리가 전진을 재개한다. 네이티브 전개·해제·포격 대상 감시 명령을 반복 이동 명령으로 덮어쓰지 않는다.

대상은 플러그인이 생성한 추가 공세 전차와 듀크다. 원본 임무 병력·아군·재활용 슬롯에는 적용하지 않는다. 등장 대기·수송선 탑승/하차·락다운·스테이시스·마엘스트롬·기존 전환 명령 도중에는 새 전환을 지시하지 않는다. 섬맵의 전차는 상륙이 끝난 후부터 판단한다. 실제 형태 변환·애니메이션·탄환·피해 처리는 게임 엔진이 수행하며 코드가 유닛 종류나 체력을 직접 바꾸지 않는다.

호스트 검사는 실제 런타임 코드에 합성 엔진 콜백을 연결해 명령과 변환 후 공세 상태 보존을 확인한다. 실제 게임에서의 공성 모드 애니메이션과 전투 체감은 사용자 플레이 확인 대상이다. QA52의 재능/저주 목록·보급25·공중 공세80%·섬 수송·중간 전설 보장은 유지한다.
