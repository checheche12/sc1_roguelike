# QA60: 망령 편대·생체 신경 봉쇄·공성 전차 우클릭

- 망령 편대: 레이스와 톰 카잔스키의 일반 공격 피해 +100%. 명중 지점 4타일 안 같은 공격층의 추가 대상은 2기에서 3기로 늘리고, 추가 피해도 기본 공격의 100%에서 200%로 올렸습니다. 지상·공중 무기와 원래 공격 횟수는 유지합니다.
- 생체 신경 봉쇄: 이미 락다운된 적은 제외합니다. 추가 대상은 발사 대기 중이거나 날아가는 다른 락다운 탄의 대상보다 아직 지정되지 않은 적을 우선합니다. 각 순위 안에서는 가까운 적을 먼저 고릅니다. 추가 대상 최대 6기·반경 6타일·생체 지속 시간 최대 2배는 유지합니다.
- 이동 공성 모드: 우클릭 화면 처리에서 변경된 기본 행동을 읽지 못하던 누락을 수정했습니다. 우클릭과 이동·공격 이동 명령 처리에 같은 소유자 DAT 속성을 연결합니다. 일반 전차와 에드먼드 듀크 공성 모드 모두 검사합니다.

네이티브 호스트 검사로 실제 피해 처리·표시값·영웅·지상/공중·교본 조합과 밀집 락다운 대상 선정을 확인합니다. 우클릭은 제작 코드의 GUI 콜백과 명령 처리 콜백에서 변경된 RightClickAction을 읽는 경로를 검사합니다. 실제 게임의 우클릭 이동·공격 이동과 전투 밸런스는 플레이 확인이 필요합니다.

QA59 에너지 시전 조건·툴팁과 테란 오리지널 3번 본진 가스 5,000을 포함합니다. 기존 재능 ID·획득 기록·확정 입력은 유지합니다. 실행기 종료 원인 추적은 중단 상태입니다.
