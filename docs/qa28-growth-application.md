# QA28 성장 적용 오류 수정

QA26·QA27에서 끝없는 증원, 공세 공격력 또는 체력 저주를 선택하면 정상 저장 후 게임 적용 단계가 `rank_slots`로 거부되어 성장 오류 10이 발생할 수 있었습니다. 2026-10-19 17:26:56 사용자 로그에서는 끝없는 증원 첫 중첩에서 발생했습니다.

무제한 중첩 카운터는 기존 1바이트 저장 위치를 유지하면서 비어 있던 랭크 영역의 29~31번에 전체 값을 함께 전달합니다. 통신 검사는 이 형식을 허용했지만 실제 효과 적용부는 그 영역이 모두 0이어야 한다는 이전 조건을 유지하고 있었습니다.

통신 수신과 실제 적용이 동일한 저장 영역 검사를 사용하도록 수정했습니다. 비어 있어야 하는 21~28번은 계속 검사하고, 확장 카운터가 있으면 기존 바이트 값과 일치해야 합니다. 기존 버전의 바이트 전용 기록도 읽습니다. 선택 기록이나 능력치·공세 밸런스는 변경하지 않습니다.

회귀 검사는 모의 게임 호스트에서 실제 통신 수신 → 프로덕션 효과 적용 콜백을 연결합니다. 증원·공격력·체력 각각 1·2·3·255·256·1000·32비트 최댓값을 첫 단계와 다음 단계에 적용하며, 비정상 예약 영역·불일치 카운터·구형 형식의 확장값은 거부합니다. 기존 적용 조건으로 동일 검사가 `rank_slots`에서 실패하는 것도 재현했습니다.

게임에서 선택한 재능·저주는 오류 전에 이미 저장되어 있으므로 성장 기록을 초기화할 필요가 없습니다. QA28 관리자로 패치를 업데이트하고 임무를 다시 시작하면 저장된 선택을 복원할 수 있습니다. 자동 검사는 실제 게임 재실행·전투 밸런스 검증을 대신하지 않습니다.
