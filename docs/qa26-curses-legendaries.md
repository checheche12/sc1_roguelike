# QA26: 공세의 압박과 전설의 돌파력

목표는 막아낼 수 있는 공세와 전선을 주고받는 전투다. 일반 저주 하나가 기본 공세를 대체하는 대신, 기본 공세에도 압박을 두고 선택한 저주가 그 성격을 강화한다. 전설은 그 압박 속에서 돌파하거나 재정비할 기회를 제공한다.

## 저주와 공세

끈질긴 후미대는 삭제했다. 저장 위치 25는 다른 효과로 재사용하지 않으며, 기존 보유 값이 전달되어도 생성·선택 경로에서 비활성화한다. 아직 확정하지 않은 선택지에 후미대가 있으면 원래 후보와 UUID를 기록한 뒤 교체한다.

| 항목 | QA26 |
| --- | --- |
| 기본 추가 공세 | 기존 인구 예산의 120%, 정수 내림. 준비 시간·간격·240인구 생존 상한 유지 |
| 끝없는 증원 | 선택마다 +25%, +30%, +35%…를 기본 편성에 합산. 누적 +25/+55/+90/+130%, 선택 상한 없음 |
| 군비 경쟁 | 선택마다 +10%, +15%, +20%…를 기본 공격력에 합산. 누적 +10/+25/+45/+70%, 선택 상한 없음 |
| 악마의 생명력 | 선택마다 +10%, +15%, +20%…를 기본 체력에 합산. 누적 +10/+25/+45/+70%, 선택 상한 없음 |
| 일꾼 공습부대 | 기본 2/6/10기, 새 선택 최대 3회. 증원량 증가 적용 후 내림. 기존 85% 감소를 중복 적용하지 않음 |
| 시간 가속 | 중첩당 +7.5% → +10% |
| 망자의 지원군 | 최초 8인구 → 9인구, 추가 중첩 +4인구·20킬·60초 유지 |
| 정예 선봉 | 정예 체력 +50% → +60%, 공격 +20% → +25% |
| 긴급 방어막 | 일반 공격 피해 감소 25% → 28% |
| 흡혈 병사 | 중첩당 실제 체력 피해의 10% → 12% 회복 |
| 후속 예비대 | 중첩당 본 공세 예산의 50% → 55% |
| 나머지 특수 편성 | 영웅과 호위를 포함해 해당 편성의 최대 체력 10% 증가. 편성 수량·주기 유지 |

전설 저주 선택은 캠페인 절반 지점부터 열린다. 10임무 캠페인은 9번째에서 5번째로, 8임무 캠페인은 7번째에서 4번째로 앞당겼다. 같은 논리적 순번의 분기는 같은 등급을 사용한다. 임무 안에서 특수 공세가 출발할 수 있는 시간과 대응 수단 검사는 유지한다.

## 전설 재능

현재 전설 20개를 검토했다. 방사선 연쇄·EMP·정신 지배·스톰 등 이미 고유 효과가 큰 전설과 최근 하향한 전방위 요격은 유지하고, 네 가지에 다음 효과를 추가했다.

| 전설 | 추가 효과 |
| --- | --- |
| 삼중 야마토 | 세 탄착지의 3타일 안 다른 적 최대 6기에 원래 야마토 피해의 50% 폭발. 한 시전에서 같은 적에게 중복 적용하지 않으며 세 직접 피격 대상은 제외 |
| 하늘을 덮는 군체 | 군체 안 아군 전투 유닛이 초당 최대 체력 1% 회복. 공중·기계 포함, 겹친 군체의 회복은 중복되지 않음 |
| 실체화 환영 | 소멸 시 반경 3타일의 적 최대 4기에 최대 체력 25%, 최대 100 피해 |
| 정지장 폭쇄 | 해제 폭발 주변 3타일의 적 최대 6기에 이동 속도 50% 감소, 3초 |

폭발은 아군을 공격하지 않으며, 생성 효과가 스스로 재발동하는 순환은 만들지 않는다. 연쇄 방사선과 캐리어의 추가 타격 1기 조정은 유지한다.

## 기록과 검증

증원·공격·체력 중첩은 기존 1바이트 값에 더해 사용하지 않던 스냅샷 끝의 32비트 영역으로 전달한다. 255회를 넘는 중첩이 인접한 저주를 덮어쓰지 않는지, 기존 스냅샷을 읽는지, 감소하거나 형식이 불일치하는 입력을 거부하는지 검사한다.

이전 배포본과 성장 기록 삭제는 사용자의 명시적 지시다. 새 배포 검증을 마친 뒤 정리한다. 원본 설계·사용자 작업실 문서는 보존한다.

자동 검사는 선택·저장·프로토콜·네이티브 호스트 동작을 확인한다. 실제 화면 연출과 임무 완주·전투 체감은 새 성장 기록으로 플레이하며 확인해야 한다.
