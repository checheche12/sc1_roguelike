# QA39 전설 역할 개편

전설을 41개(공통 3, 종족 38)로 정리하고 34개 전투 유닛 계열을 지원한다. 일꾼·수송·비전투 전설, 표적 지시탄, 감염된 테란·브루들링 전설은 새 제안과 런타임에서 제거한다. 영웅·선택 이력의 ID와 원문은 유지한다. 삭제된 재능이 포함된 미선택 묶음은 정확한 원문을 보관한 뒤 다시 발급한다.

18개 전설을 단일 표적 중심으로 바꾼다. 반복 사격·누적 공격·처형·대형 표적 사냥으로 구분하며, 단일 전설의 원래 광역 분기는 비활성화한다. 커세어는 기본 범위 공격을 유지하고 6회마다 주 대상에만 900% 추가 피해를 준다. 아콘은 실제 받은 일반 공격의 체력·보호막 피해 30%를 최대 200까지 저장해 다음 직접 공격에서 방출한다.

- 파이어뱃: 주 대상 피해 +100%, 전방 3타일·120도 부채꼴의 다른 지상 적들에게 원래 공격 100%의 실제 화염 발사체. 원래 발사체의 주변 중복 피해 및 추가 화염 재발동 방지.
- 마린: 주 대상 피해 +25%, 같은 적 3회 공격마다 원래 공격 300% 추가. 광역 발동 제거.
- 저글링: 공격마다 적 체력 방어력 1을 끝없이 감소. 방어력보다 많이 쌓인 감소분은 저글링 추가 피해로 전환. 대상 수명·소유권 경계에서 초기화.
- 울트라: 주 대상 외 전방 지상 적 최대 3기에 원래 공격 70%, 주 대상과 추가 공격의 실제 체력·보호막 손실만큼 회복. 초과 피해·방어막 흡수 제외.
- 스커지: 피해 +50%, 체력 3배, 공중 표적 추격 중 받는 일반 공격 피해 75% 감소, 표적 과잉 예약 시 다른 공중 표적으로 분산. 지상 공격 제거.
- 디바우러: 산성 폭풍의 지상 400%·공중 200% 유지. 묻힌 산성 포자의 피해 증가·공격 지연을 2배 적용.
- 러커: 공중 공격 가능, 대공 피해 100%.
- 아비터: 정지장 고정 범위와 이펙트 배율 1.5배, 해제된 아군 체력·보호막 완전 회복. 에너지는 지급하지 않음.
- 퀸: 증식 브루들링을 인스네어 공격·이동 속도 85% 감소로 교체. 기본 감속과 중복 곱하지 않으며 긴 공격 간격은 별도 프레임 마감으로 유지. 폭증하는 무리의 대상당 6기·추가 3대상 유지.
- 암흑기사: 공허의 검 영웅 유지, 그림자 격노 전설 추가. 전투 중 6타일의 지상 적을 5회 순간이동 공격(각 200%), 동작 중 무적, 원위치 복귀, 재사용 12초. 남은 여유 필드 한 비트를 추가하고 기존 122개 유닛 성장 필드를 보존한다.
- 반중력 발사대·이동하는 폭풍체 영웅. 반중력의 방어력 무시 제거, 이동 폭풍체 피해 100%.

자동 검사는 합성 호스트에서 실제 배포 번역 단위·발사체·피해 콜백과 소유자 격리·무적 복원·경계·재귀 방지를 실행한다. 개인 DB와 확정 입력은 열지 않는다. 원본/출력 해시가 같은 63개 지도는 체크포인트 변환을 재검사한다. 실제 게임의 전투·HD 외형·성능과 밸런스 검증은 별도 플레이 확인이 필요하다.
