# QA47 업데이트 후 기존 기록 선택 복원

QA46을 새 폴더에서 실행하면 폴더별 마지막 기록 설정이 없어서 빈 `original.sqlite3`가 자동으로 열렸다. 그 기록으로 캠페인 3·4번째 임무를 시작하면 선행 임무가 완료되지 않아 `mission_locked` 요청 거절과 게임의 연결 오류 5가 발생한다.

새 배포 폴더에 설정이 없을 때 같은 위치의 다른 `SC1_Roguelike_*` 폴더 설정에서 가장 최근에 선택한, 현재 존재하는 기록 경로를 이어받는다. 기록 파일 내용은 읽거나 복사하지 않는다. 사용자가 현재 버전에서 이미 선택한 기록과 명시적 `--db` 입력이 우선한다. 현재 설정이 손상됐거나 선택한 기록이 사라졌다면 다른 기록으로 바꾸지 않고 다시 선택하도록 한다.

`mission_locked`에는 미완료 선행 임무명, 해당 캠페인의 완료 개수, 마지막 완료 임무, 현재 기록으로 이어서 진행할 수 있는 임무를 표시한다. 관리자는 전체 설명을 보여 주고, 게임에는 동일한 진행 정보의 짧은 안내를 보낸다. 오류 응답의 기존 상태값과 승리 차단은 유지하며, 버전 2 응답의 남는 영역에 길이가 제한된 UTF-8 안내를 추가한다. 이전 관리자·로더는 기존 오류 응답을 계속 처리할 수 있다.

예를 들어 본편 프로토스 1·2번만 완료한 기록으로 4번을 시작하면 `선행 임무 미완료: 3번 고지`, `2/10개 완료 · 마지막 완료: 2번 불길 속으로`, `이어서 진행: 3번 고지`를 안내한다. 새 기록이면 `0/10개 완료 · 마지막 완료: 없음`과 `1번 출격`을 안내한다.

QA46의 전설 기본 수치 조정은 유지한다. 사용자 기록·선택 이력·확정 입력은 수정하지 않는다.
