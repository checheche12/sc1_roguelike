# QA63 — 퀸 전설 다중 대상·에너지 수정

`폭증하는 무리`의 스폰 브루들링이 주 대상과 그 주위 4타일 안의 시전 가능한 적 최대 3기를 함께 공격합니다. 대상당 6기, 총 최대 24기 생성과 브루들링 최대 체력·공격력 2배 효과를 유지합니다. 기본 시전 에너지는 150에서 100으로 낮추고, 공통 시전 효율 재능은 이 100을 기준으로 추가 적용합니다. 시전 조건·실제 차감·툴팁이 같은 비용을 사용합니다.

추가 대상 검사에 사용하던 `CheckTechTargeting(13)`은 해당 기술을 지원하지 않아 유효한 적도 거절했습니다. 원래 브루들링 무기의 `CheckWeaponTargetingFlags(57)`로 검사하도록 바꿨습니다. 시야·적대 관계·지상 대상·구조물 및 영웅 보호 조건을 유지하며 추가 발사체가 다시 확산되거나 에너지를 추가 차감하지 않습니다.

저글링 전설 `끝없는 갑각 분쇄`의 공격당 방어력 감소 0.33과 음수 방어력 추가 피해를 브루들링에도 적용합니다. 퀸이 생성한 6기 모두 같은 판정을 사용합니다.

네이티브 합성 검사에서 다중 대상 발사·4회 적중 후 24기 생성·체력/공격력 2배·에너지 경계값과 시전 효율 조합·6기의 실제 근접 콜백을 확인합니다. 이는 자동화 검사이며 실제 게임 전투 및 화면 확인은 별도입니다.
