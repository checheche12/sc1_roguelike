# QA52 소환문·섬 상륙·보상 조정

QA50 공중 기본 공세 수치(80%)를 유지한다. QA51의 추가 감소는 적용하지 않는다.

- 전장 소환문은 기존 고정 출발지·도착지와 2초 간격 이동을 유지하며, 양쪽에 짧게 끝나는 원본 리콜 필드 효과를 반복 생성한다.
- 지상 경로가 없는 생산 임무 5개(108, 204, 305, 503, 606)는 희귀·영웅·전설 지상 특수 공세를 원래 편성대로 수송선에 태워 상륙시킨다. 새로 생성한 공세 병력에만 탑승·하차 명령을 내리고 원본 지도 병력은 그대로 둔다. 수송 중 일반 공세 명령과 주문 시전이 탑승·하차를 덮어쓰지 않는다.
- 본편/BW의 각 캠페인에서 절반을 지난 첫 논리 임무의 첫 보상을 전설 꾸러미로 보장한다. 10개 임무 캠페인은 6번째, 8개 임무 캠페인은 5번째다. 첫 임무 보장과 기존 보상 총수는 유지한다. 분기 지도는 같은 보상 권리를 공유하며 이미 발급된 후보와 완료한 보상을 소급 변경하지 않는다. 지연 보충은 없다.
- 임무 보급 상자는 저주 중첩당 미네랄 25·가스 25로 줄인다. 기존 기록은 다음 불러오기에서 최신 효과 설명과 메타데이터를 반영한다. 원문·확정 입력·전송 위치·획득 기록은 보존한다.
- 화력 교범은 기존 무작위 짝짓기를 유지한다. 프로토스 시나리오 19개에서 각각 128개 시드로 검사했으며 드라군+리버에 고정된 임무는 발견하지 못했다. 사용자의 실제 기록에서 같은 조합이 반복된 원인까지 재현한 것은 아니다.

검증은 원본 지형 자료, 실제 런타임 코드를 사용하는 합성 호스트, 임시 SQLite 기록, 네이티브 UI·프로토콜 및 포터블 패키지 자체 검사로 수행한다. 실제 게임 실행, 효과의 화면 외관, 임무 완주와 전투 체감 검증은 포함하지 않는다. 이전 QA 배포 폴더·ZIP은 QA52 검증 후 정리하며 분석·검증 기록과 사용자 저장 파일은 보존한다.
