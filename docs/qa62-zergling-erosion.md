# QA62 변경 내용

저글링 전설 **끝없는 갑각 분쇄**의 공격당 체력 방어력 감소를 **1 → 0.33**으로 낮췄습니다. 저글링과 디바우링 원에 적용됩니다.

소수점은 공격마다 버리지 않고 누적합니다. 3회 공격하면 0.99, 4회면 1.32, 100회면 33이 감소합니다. 방어력이 0 아래로 내려간 누적분을 저글링의 추가 피해로 바꾸는 기존 효과도 같은 비율로 완화했습니다.

방어력 업그레이드를 포함한 체력 방어력에 적용하며, 대상의 소유자가 바뀌거나 새 유닛으로 생성되면 누적이 초기화됩니다. 게임의 체력 계산 정밀도에 맞춰 소수점 효과를 반영합니다.

게임 내 설명도 0.33으로 갱신했습니다. QA61의 타워 재능·업그레이드, 벌처 일반형 공격, 리버 무료 스캐럽은 유지합니다. 기존 재능·저주의 ID와 저장 위치, 63개 지도는 변경하지 않았습니다.

새 패키지에서 패치를 설치·업데이트한 뒤 임무를 새로 시작해 주세요. 자동 검증은 네이티브 피해 처리와 저장·표시 호환성을 확인하며, 실제 전투 밸런스는 플레이 확인이 남아 있습니다.
