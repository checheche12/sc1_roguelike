# QA43 성장 적용 오류 10 수정

QA42 프로토스 첫 임무에서 선택 완료 뒤 `stat_engine_patch_changed`로 성장 적용이 중단됐다. 로컬 오류 로그와 사용자가 실행한 게임의 읽기 전용 검사에서 기존 야마토 에너지 배열은 0이고, 로더가 연결한 세 참조는 모두 새 배열의 150을 읽는 것을 확인했다. 기존 코드는 이전 배열에 150이 남아 있어야 한다고 검사했다.

에너지 배열을 참조하는 검증된 세 명령의 연산 형식을 확인하고 로더가 바꾼 변위로 실제 배열을 찾는다. 세 주소의 일치, 읽기 가능 여부와 기본 비용 150은 계속 검증한다. 성장 적용 후 실제 배열에도 소유자별 50/150 비용을 적용하고 중첩 호출 뒤 원상 복구한다. 다른 엔진 검증이 실패하면 각 기능의 구체적인 실패 단계를 로그에 남긴다.

회귀 검사는 실제 관측한 배열 이동과 이전 배열의 0을 재현하여 전체 성장 적용을 실행한다. 실제 비용 차감, 아군·적과 중첩 소유자 복원, 참조 명령 손상·주소 불일치·비정상 비용 거부도 검사한다. 개인 기록을 열거나 수정하지 않는다. 수정본의 실제 게임 재실행과 전투 검증은 사용자 확인이 남아 있다.
