원본 기지6곳과 실제 지형의 연결 지역을 비교해 대상2곳이 같은 플레이어 섬에 있는 것을 확인했습니다. 기지 나열 순서, 섬 기지 지연 등장, 생성 실패 재시도, 중복 지급과 다른 임무 회귀를 자동 검사합니다. 실제 게임 화면·임무 완주 확인과는 구별합니다.
