# QA46 전설 기본 수치 조정

전설 하나만으로 기본 수치가 3배 이상이 되는 강화를 낮춘다. 반복 공격·처형·전염·반격 같은 고유 발동 구조와 다른 재능의 조합은 유지한다.

| 전설 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 질럿 태양의 결투 | 일반 공격 +200% | +75% |
| 벌처 사냥꾼 주행 사격 | 일반 공격 +200% | +100% |
| 골리앗 삼중 집중 조준 | 일반 공격 +200% | +100% |
| 스파이더 마인 대형 성형 지뢰 | 일반 공격 +500% | +150% |
| 뮤탈리스크 집중 쐐기 | 일반 공격 +200% | +100% |
| 리버 결전 갑충탄 | 스캐럽 공격 +400% | +150% |
| 과학선 방사선 연쇄 | 이레디에이트 피해 3배 | 2배 |
| 고스트 생체 신경 봉쇄 | 생체 락다운 지속 시간 최대 4배 | 최대 2배 |
| 스커지 정밀 갈귀 | 최대 체력 3배 | 2배 |
| 디파일러 죽음의 역병 | 플레이그 피해 4배 | 2배 |
| 디바우러 산성 폭풍 | 지상 피해 400% | 200% |
| 하이 템플러 중첩 폭풍 | 스톰 반경 +200% | +100% |

질럿은 적 체력이 50% 이하면 원래 공격의 +200%를 더 주는 처형 효과를 유지한다. 따라서 전설 단독 배율은 일반 대상 3배→1.75배, 체력이 절반 이하인 대상 5배→3.75배다. 공격 교범으로 오른 기본 공격에도 새 배율이 적용된다. 벌처의 이동 중 +100%, 디바우러의 공중 피해 200%와 산성 포자 효과 2배, 드라군의 누적 3타·250% 추가 피해는 유지한다.

현재 설명과 네이티브 계산을 함께 갱신한다. 저장 ID·전송 위치·사용자 원문·확정 입력·발급된 선택지와 동결 스냅샷은 보존한다. 자동 검사는 실제 게임 전투 체감 검증을 대신하지 않는다.
