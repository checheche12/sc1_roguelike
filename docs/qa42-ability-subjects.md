# QA42 능력의 적용 유닛 표시

현재 재능·저주 설명에 주체 또는 적용 대상을 명시한다. 유닛 전용 능력은 마린·골리앗·과학선 등 유닛 이름으로 시작하고, 캐리어의 인터셉터·리버의 스캐럽처럼 모체와 탄약의 관계도 표시한다. 공통 특성과 저주는 아군·적 추가 공세 등 적용 집단을 표시한다. 이미 주체가 명확한 문장은 유지한다.

새 카탈로그, 게임 선택창의 효과 문자열, 관리자에 표시되는 저장 선택지와 HTML을 함께 갱신한다. 저장 묶음은 각 구성원의 주체를 표시하되, 원본 JSON과 수치·조건은 보존한다. 퀸의 마비성 인스네어 대상 표기도 주문 이름에 맞춘다. 효과 설명 전용 갱신 번호를 사용하며 게임 효과·영구 ID·저장 필드는 바꾸지 않는다.

현재 설명 113개를 수정하고 활성 효과 315개의 주체를 검사한다. 새 게임 화면 외관과 구분하여, 합성 네이티브 선택창에서 설명 전체·줄바꿈·텍스트 버퍼를 검사한다. 변경하지 않은 63개 지도의 기존 검증과 해시를 상속한다.
