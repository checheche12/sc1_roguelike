실제 스타크래프트 전투 로그 검증

이 도구는 설치된 64비트 스타크래프트와 이 저장소의 최신 전투 코드를
전용 시험장에서 실행한다. 게임 설치 파일, 캠페인 기록, 활성 패치 포인터는
바꾸지 않는다. 스타크래프트가 실행 중이면 검사를 시작하지 않는다.

저장소 루트에서 실행:
python -B -X utf8 -m sc1.diagnostics.live_combat check --output analysis/live_checks --game D:/blizard/StarCraft/x86_64/StarCraft.exe

검사에는 로컬 MSVC Build Tools와 현재 관리자 배포본이 필요하다.
새 진단 DLL을 별도 폴더에 빌드하고 게임을 실행한다. 약 7분 걸린다.
네 대조군: 재능 없음 / A 단독 / B 단독 / A+B.

검사 대상:
- 일반 공격의 실제 체력·실드 감소와 공격 간격
- 고스트 일반형 전환과 방어 무시
- 스커지 교범 4중첩과 방어 무시
- 전방위 전함의 무료 야마토와 삼중 야마토
- 다크 스웜·인스네어의 범위 경계
- 락다운의 기본·연장·생체 대상 지속시간과 최종 해제
- 전염된 산성 포자의 강화 상태
- 벌처의 추가 범위 타격과 방어 무시

각 실행 폴더의 파일:
manifest.json: 소스, 진단 DLL, 게임, 로더, 지도 해시와 검사 구성
engine.jsonl: 실제 명중 전후 Q8 체력·실드, 효과 타이머, 공격 횟수
run.json: 실제 게임 PID, 종료 코드, 시간 초과, 해당 PID의 크래시 덤프
verification.json: 항목별 예상값·관측값·통과 여부
verifier.py: 준비 시점의 판정 코드 사본(새 실행부터 포함)
sc1_native.log / loader_stdout.log: 원래 플러그인과 로더 로그
crash_*.dmp: 이 검사에서 실행한 게임의 덤프가 확인된 경우 보관

Q8 값은 256으로 나누면 게임의 피해·체력 수치가 된다.
예: 소형 SCV에 야마토 원시 피해 260은 폭발형 크기 보정 후 130 피해.
로그 누락, 중간 종료, 잘린 로그, 예상 밖 피해값은 통과로 취급하지 않는다.
공격속도는 공통된 안정 구간의 중앙값으로 비교하며, 1프레임 미만의
우연한 평균 차이를 시너지 입증으로 취급하지 않는다.
마지막 terminal=complete와 실제 게임 종료 코드 0을 모두 확인한다.

이는 전용 시험장 검사다. 모든 캠페인 완주, 모든 재능 조합, 화면 외관,
일반 종료 동작을 검증하지 않는다. 검사는 마지막에 자체 종료한다.
진단 DLL은 제품 전투 소스를 그대로 복사해 로그 관측기를 덧붙여 빌드한다.
배포 DLL 그 자체와 바이너리가 같지는 않다.
